📝 玩转 Markdown

别再傻乎乎地用记事本写笔记了。十分钟学会，受用一辈子。

#工具 #写作 #效率

📖 这是什么？

Markdown 是一种轻量级的标记语言。它像极了武林秘籍里的 “轻功”——学起来只需要十分钟，但用好了能让你飞一辈子。

你是不是还在忍受 Word 排版时图片乱飞、格式崩溃的痛苦？
或者写了半天笔记，粘到网页上丑得自己都不想看？

Markdown 就是来解决这个问题的。它让你用纯文本写出结构清晰、 排版美观的文档，而且可以无缝转换成 HTML、PDF、Word 等任何格式。

🔓 学完这一课，你将解锁

  • 优雅地写出一份连程序员看了都想 Star 的笔记
  • 从此告别鼠标狂点格式刷的原始时代
  • 你的笔记可以在任何平台（GitHub、博客、文档站）完美展示
  • 写漏洞报告、技术文档时事半功倍

⚡ Markdown 核心语法

这套教程不跟你讲复杂的语法树，只教你最常用的 5% 语法， 覆盖你 95% 的写作场景。

# 标题

用 # 符号表示标题，一共六级：

# 一级标题
                    ## 二级标题
                    ### 三级标题
                    #### 四级标题
                    ##### 五级标题
                    ###### 六级标题

• 列表

无序列表用 -、* 或 +：

- 苹果
        - 香蕉
          - 子列表：帝王蕉
        - 橙子

有序列表用数字加点：

1. 第一步
        2. 第二步
        3. 第三步

🔗 链接与图片

[点击这里跳转](https://example.com)
        ![图片描述](/assets/images/screenshot.png)

💻 代码块

用三个反引号 ``` 包裹代码，可以指定语言：

```python
        def hello():
            print("Hello, Night Keeper!")
        ```

行内代码用单个反引号：print("hello")

📌 引用

> 长夜将至，我从今开始守夜，今夜如此，夜夜皆然。

长夜将至，我从今开始守夜，今夜如此，夜夜皆然。

💪 实战练习

打开你的 VS Code，新建一个 README.md 文件，试着写一篇自我介绍：

  1. 用 # 写一个大标题
  2. 用 ## 写三个小标题
  3. 在每个小标题下列一个无序列表
  4. 在最后加一个 > 引用，写一句守夜者誓言
